# Week 7 in-class lab — Gradient boosting

[Open the lab notebook](notebooks/week_07_boosting_lab.ipynb)

This lab is completed during class and is separate from both take-home exercises.

## Learning sequence

1. Calculate one residual-correction step by hand.
2. Connect the calculation to the gradient-boosting update.
3. Compare one decision tree, Random Forest, and histogram gradient boosting under one validation design.
4. Change learning rate, number of leaves, and minimum leaf support one at a time.
5. Set up XGBoost and LightGBM as additional implementations.
6. Select a model using probability quality, stability, runtime, and a business guardrail.

## In-class evidence

- Completed residual table
- Short explanation of the learning-rate effect
- Four-line model recommendation
- Parameter experiment record
- Individual retrieval response

The lab uses a simulated customer-retention setting so that it does not expose or complete the BookingGuard take-home analysis.
